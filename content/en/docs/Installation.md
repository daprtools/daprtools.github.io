### Get DaprDesigner running on your system

1. Install Java 17 (preferably using [SDKMAN](https://sdkman.io))
2. Install [Obeo Designer](https://www.obeodesigner.com/en/download) . Please note some special instructions for running Obeo Designer on **Mac**
3. Start Obeo Designer and click Help / Install new software...
4. Select Obeo update site from dropdown and select the additional features (see image below)
5. Install and restart Obeo Designer. 
6. Install Daprdesigner plugin from this [zip file](). (Instructions on how to install eclipse plugins from zip file described [here](https://stackoverflow.com/questions/31553376/eclipse-how-to-install-a-plugin-manually/31553745))
7. Restart Obeo Designer and you are all set !!
